# 港股模擬盤 · apex-jade-onyx-harbor

香港股票**紙上交易**網站。本金 **HK$10,000**，目標 **HK$100,000,000**（財富自由）。

## 玩法

- **恒生指數迷你**（HK$1 / 點，最高 10 倍檔桿）及港股／盈富基金
- 含 **0434 博雅互動**、**3988 中國銀行**
- 買入以**賣出價 Ask**成交，賣出以**買入價 Bid**成交（港股紅升綠跌）
- 陰陽燭：5 分鐘 / 15 分鐘 / 日線，附 SMA、RSI、形態教學提示
- Lo-fi 背景音樂（需按一下才播放，瀏覽器限制）
- 進度保存在本機瀏覽器

## 開啟網站

1. 下載本倉庫，用瀏覽器打開 [`index.html`](index.html)
2. 或在 GitHub：**Settings → Pages → Deploy from a branch → `main` / `/ (root)`**

私有倉庫的 GitHub Pages 需要 GitHub Pro；亦可把倉庫改為 Public 後再啟用 Pages。
